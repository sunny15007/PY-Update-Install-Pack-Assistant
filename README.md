# PY更新安装打包助手

面向 Windows 的 Python 环境管理与脚本打包工具，基于 Python + Tkinter 开发，
界面简洁，无需命令行基础即可使用。

当前版本：v1.0.0

## 功能

- 检测 Python / pip 环境状态
- 一键安装常用库
- 查看所有已安装库，支持单个或批量卸载
- 库清单可复制到报告区或剪贴板
- 从 requirements.txt 恢复全部依赖
- 将 Python 脚本打包成 EXE（支持 PyInstaller 与 Nuitka 两种方式）
- 检查 Python 库是否有更新

## 下载使用

适用于 Windows。前往本仓库的 Releases 页面，下载最新版的 exe 文件，
双击即可运行，无需安装 Python。

## 安全说明

- 打包产生的临时目录只清理工具自建的子文件夹，不会影响其他文件
- 删除操作经由回收站，可恢复
- 工具打包自身时会自动复制后静默处理
